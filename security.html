Security FAQ

Will Payerkart sign a BAA?

Yes. A Business Associate Agreement is available for teams that need one.

How is patient data protected?

Data is encrypted in transit and at rest, access is scoped per API key and role-based on the server, and every request is logged.

Can we audit who checked a patient's eligibility?

Yes. Each eligibility and claim status request is recorded with who made it, when, and for which patient or claim. The log is searchable by API key, patient, date and endpoint.

Can we revoke access quickly?

Yes. API keys are scoped and revocable from the admin console.
