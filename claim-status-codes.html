Claim status code (277) translator

Turn 277 claim status category codes into plain English, and see what to do next. Search by code or by word.

CodeCategoryWhat it meansWhat to do
A0Acknowledgement / ForwardedThe claim was forwarded to another entity.Check which payer it went to.
A1Acknowledgement / ReceiptReceived, not yet accepted for processing.Wait; check again in a few days.
A2Acknowledgement / Accepted into adjudicationAccepted and entered the payer's system.Nothing to do yet.
A3Acknowledgement / Returned as unprocessableReturned without processing.Read the status code, correct the claim data in your billing system.
A4Acknowledgement / Not foundThe payer can't find the claim.Confirm it was sent and to which payer.
A6Acknowledgement / Rejected for missing informationRejected: something required is missing.Add the missing data named in the status code.
A7Acknowledgement / Rejected for invalid informationRejected: a value is invalid.Fix the invalid value named in the status code.
A8Acknowledgement / Rejected for relational field in errorRejected: two fields conflict.Check related fields, e.g. dates or codes that don't match.
P0Pending / Adjudication, details not specifiedIn process; no detail given.Wait; check again later.
P1Pending / In processBeing processed.Wait; check again later.
P2Pending / Payer reviewUnder payer review.Watch for a request for information.
P3Pending / Provider requested informationWaiting on information from you.Send the requested information promptly.
P4Pending / Patient requested informationWaiting on information from the patient.Ask the patient to contact their plan.
P5Pending / Payer administrative or system holdHeld on the payer side.Wait; contact the payer if it persists.
F0FinalizedProcessing is complete.Check the remittance for the outcome.
F1Finalized / PaymentThe claim or line has been paid.Post the payment from the remittance.
F2Finalized / DenialThe claim or line has been denied.Read the reason code, fix the cause, then follow up.
F3Finalized / RevisedThe payer revised the adjudication.Review the new remittance.
F4Finalized / Adjudication complete, no payment forthcomingDone, but nothing will be paid (e.g. applied to deductible).Bill the patient responsibility if applicable.
R0Requests for additional information / GeneralThe payer needs more information.Read the status code and respond.
E0Response not possible / Error on submitted requestYour status request had an error.Correct the request data and ask again.
E1Response not possible / System statusThe payer system can't respond right now.Retry later.
E2Information holder is not respondingNo response from the payer.Retry later.
D0Data search unsuccessfulNo matching claim found.Check claim number, dates and patient details.

Based on the X12 code sets used in HIPAA transactions. Descriptions are plain-English summaries; payers may use codes differently, so check your payer's companion guide.

Common denial and rejection codes, translated

Payer codeWhat the payer sendsWhat Payerkart shows staffSuggested fix
AAA 72
Eligibility		Invalid or missing member IDThe payer doesn't recognise the member ID that was sent.Re-check the card (prefixes and suffixes are often dropped), or re-scan it, then run eligibility again.
AAA 71
Eligibility		Birth date doesn't match payer recordsThe date of birth in the EHR doesn't match what the payer has on file.Confirm the date of birth with the patient. Check you sent the patient's details, not the subscriber's.
AAA 75
Eligibility		Subscriber not foundThe payer can't find anyone matching the name, ID and date of birth sent.Check name spelling and payer selection. Try the subscriber's details if the patient is a dependent.
CARC 27
Claim		Expenses incurred after coverage terminatedThe plan had ended before the date of service.Re-verify eligibility for that date and ask the patient for current insurance before billing again.
CARC 22
Claim		Covered by another payer (coordination of benefits)The payer thinks another plan should pay first.Update primary and secondary coverage with the patient, then bill the primary plan.
